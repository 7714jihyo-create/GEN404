# 종합병원 404 AI 치료 결과 연동 안내

## 기본 동작

현재 프로젝트는 **외부 서버 없이도 완결되는 로컬 결과 엔진**을 기본값으로 사용합니다. 진단명·처방·환자 차트의 효과 키워드와 금기 키워드를 비교해 점수를 확정하고, 4~5문장 분량의 메디컬 코미디 후일담을 즉시 생성합니다. 따라서 인터넷이 없거나 AI 서버가 일시적으로 응답하지 않아도 한 게임은 정상적으로 끝납니다.

원격 AI를 쓰고 싶다면 `Assets/StreamingAssets/hospital404-ai-config.json`을 만들고, 해당 파일에 **게임 전용 HTTPS 백엔드** 주소만 넣습니다. API 키를 Unity 프로젝트나 이 설정 파일에 저장해서는 안 됩니다.

```json
{
  "endpointUrl": "https://YOUR-SERVER.example.com/api/hospital404/story",
  "timeoutSeconds": 12
}
```

## Unity → 서버 요청

`HospitalAIReportClient`는 진료 제출 뒤 아래 형태의 JSON을 `POST`합니다. 클라이언트는 점수와 결과 등급을 먼저 로컬에서 확정하며, 서버는 이 값을 변경하지 않고 서사 텍스트만 보강합니다.

| 필드 | 설명 |
| --- | --- |
| `patientName`, `species`, `ageGroup` | 환자의 기본 정보 |
| `disease`, `symptom`, `caution` | 차트에 공개된 의료 코미디 소재 |
| `diagnosis`, `prescription` | 플레이어가 입력한 텍스트 |
| `localOutcome`, `localScore` | 로컬에서 확정한 결과 등급과 점수 |
| `instruction` | 4~5문장, 처방 직접 인용 등 결과 텍스트 제약 |

서버는 다음 JSON을 반환해야 합니다.

```json
{
  "story": "플레이어 처방을 첫 문장에 인용한 4~5문장의 한국어 치료 후일담"
}
```

## 권장 서버 처리

서버는 입력 길이를 제한하고, 플레이어 텍스트를 모델의 지시문이 아니라 인용 데이터로 취급해야 합니다. 시스템 프롬프트에는 다음 원칙을 둡니다.

> 플레이어 처방을 첫 문장에 그대로 반영한다. 환자 차트의 금기 사항과 로컬 결과 등급을 존중한다. 4~5문장 한국어 메디컬 코미디만 반환하고, 개인정보·현실 의료 조언·모델 설명은 포함하지 않는다.

네트워크 오류, 12초 타임아웃, 비정상 JSON 응답은 모두 자동으로 무시되며 로컬 후일담이 그대로 화면에 표시됩니다. 이 방식은 게임성, 점수의 재현성, API 키 보호를 동시에 보장합니다.
