# 🏥 종합병원 404 프로토타입 [https://epfyesul.gensparkspace.com/]

## 🎮 게임 개요

**종합병원 404**는 의사가 되어 이상한 환자들을 진단하는 게임입니다. AI가 플레이어의 진단서를 바탕으로 웹소설·메디컬 드라마 형식의 결과 보고서를 생성하며, 총 세 번의 진단 결과에 따라 점수를 받습니다.

---

## ✅ 기능

### 게임 시스템

| 화면 | 내용 |
| --- | --- |
| 타이틀 | 게임 소개와 시작 |
| 라운드 시작 | 다음 환자 호출 안내 |
| 초진 차트 | 이름·종족·연령대·질병·증상·특약/알레르기/금기 공개 |
| 진단서 작성 | 진단명과 처방을 자유롭게 입력 |
| AI 시뮬레이션 | 로컬 결과 엔진 또는 선택형 원격 AI 서사 생성 |
| 결과 보고서 | 웹소설형 치료 후일담과 점수 |
| 최종 점수 | 3라운드 누적 점수·의사 등급·진료 기록 |

### AI 보고서 엔진

| 항목 | 내용 |
| --- | --- |
| 처방 반영 | 유저가 쓴 치료법을 후일담 첫 문장에 직접 인용합니다. |
| 결과 서사 | 성공·부분 성공·실패·방치에 따라 4~5문장 메디컬 코미디를 생성합니다. |
| 점수 | 환자별 효과 키워드와 금기 키워드에 따라 기본 점수를 계산하고, 진단명 작성 보너스를 적용합니다. |
| 안정성 | 외부 AI 서버가 없거나 통신에 실패해도 로컬 결과 엔진이 즉시 동작합니다. |

## Unity 구현 현황

메인 브랜치에는 플레이 가능한 기본 진료 루프가 추가되었습니다. `StartScene`에서 시작하면 세 명의 환자가 중복 없이 배정되고, `GameScene`에서 차트를 확인한 뒤 진단명과 처방을 작성합니다. 처방의 효과·금기 키워드를 바탕으로 치료 결과와 점수가 산정되며, 3라운드 뒤 `ResultScene`에서 총점·의사 등급·환자별 진료 기록을 확인할 수 있습니다.

| 구성 요소 | 구현 내용 |
| --- | --- |
| 환자 차트 | 이름, 종족, 연령대, 병명, 증상, 특약·알레르기·금기 사항을 실제 데이터로 표시합니다. |
| 진료 결과 | 각 처방을 첫 문장에 반영한 4~5문장 분량의 치료 후일담과 점수를 표시합니다. |
| 3라운드 | 냉장고, 강아지, 전자레인지, 공유기, 로봇, 외계인 환자 풀에서 세 명을 무작위 배정합니다. |
| 최종 결과 | 누적 점수와 의사 등급, 환자별 결과 요약을 제공합니다. |
| AI 연동 | 기본은 오프라인 로컬 결과 엔진이며, HTTPS 서버를 연결하면 AI 서사로 선택적 보강이 가능합니다. |

세부 데이터와 점수 규칙은 [`Docs/HOSPITAL404_IMPLEMENTATION_PLAN.md`](Docs/HOSPITAL404_IMPLEMENTATION_PLAN.md)를, 원격 AI 서버 계약은 [`Docs/AI_REPORT_INTEGRATION.md`](Docs/AI_REPORT_INTEGRATION.md)를 참고하세요.
